# Fact-check procedure
1. Re-fetch sources yourself; never trust the research summary.
2. Split into atomic claims: fact/allegation/opinion/unknown.
3. Require 2+ genuinely independent publishers for 'verified'.
4. Report verified/disputed/unresolved + block_reason; block when unverifiable.
